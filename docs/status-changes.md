## How to read the list

- `(sunsetting)` — winding down; do not apply, kept for reference.
- `(acquired by X)` — the program continues under a new owner.
- `(legacy)` — superseded by a newer program from the same provider.
- Amount changes that don't alter the program's existence are **not** logged here — the entry is simply updated with a fresh `verified_date`.
